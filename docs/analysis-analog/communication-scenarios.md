# コミュニケーション図 事前/事後条件・シナリオ

## 蓋閉から沸騰開始を経由して保温まで

### 事前条件

水が適量であること
蓋が開いていること

### 事後条件

保温中(保温行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは蓋を閉める
2. 蓋は(3sec後)ポットへ蓋閉を通知する
3. ポットは水位へ水位更新を指示する
4. ポットは給湯口へ蓋閉を通知する
5. 給湯口は解除ボタンへ有効性の有効を指示する
6. ポットは保温モードへ蓋閉を通知する
7. 保温モードは保温設定ボタンの有効性の有効を指示する
// ポットは自身へ沸騰要求を通知する
8. ポットは水位の位置と満水を確認する
9. ポットは温度制御へ, 沸騰を指示する  // ポットは加熱中(沸騰行為)へ遷移
10. 温度制御は温度表示へ水温の温度出力を指示する
// 以後, この温度出力の指示は温度制御のサーミスタ読み取りの周期で定期実行
11. ポットは温度エラー監視へ, 加熱監視を指示する
12. ポットはランプの点灯を変える {沸騰ランプ点灯, 保温ランプ消灯}
// 待ち. 温度制御はサーミスタとヒータと温度表示を, 温度エラー監視は温度制御の水温を, 定期で更新
13. 温度制御は沸点到達をポットへ通知する
14. ポットは温度制御へ, カルキ抜きを指示する // ポットはカルキ抜き中(沸騰行為)へ遷移
15. ポットは温度エラー監視へ, カルキ抜き監視を指示する
// 待ち. 上の待ちと大体同じ.
16. 温度制御は(3分経過後)沸騰処理完了をポットへ通知する
17. ポットは保温モードの保温温度を確認する  // ポットは保温中(保温行為)へ遷移
18. ポットは温度制御へ保温(保温温度)を指示する
19. ポットは温度エラー監視へ保温監視を指示する
20. ポットは保温モードへ保温行為の開始を通知する
21. 保温モードは沸騰ボタンへ有効性の有効を指示する
22. ポットは給湯口へ保温行為の開始を通知する
23. 給湯口は給湯ボタンへ有効性の有効を指示する
24. ポットはブザーへ3回鳴動を指示する
25. ポットはランプの点灯を変える {沸騰ランプ点灯, 保温ランプ消灯}

## 沸騰ボタン押下から沸騰開始まで

### 事前条件

保温中(保温行為)であること

### 事後条件

加熱中(沸騰行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは沸騰ボタンを押す
2. 沸騰ボタンは(100msec後)押されたことを保温モードに通知する
3. 保温モードはポットへ沸騰要求を通知する
4. 保温モードはブザーへ単発鳴動を指示する
5. ポットは水位の位置と満水を確認する
6. ポットは温度制御へ, 沸騰を指示する  // ポットは加熱中(沸騰行為)へ遷移
// 以後, 蓋閉から...の "ポットは温度制御へ, 沸騰を指示する" の流れへ乗る

## 保温モードボタン押下から保温モードが変更されるまで

### 事前条件

蓋が閉じていること

### 事後条件

保温モードが変更されていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは保温設定ボタンを押す
2. 保温設定ボタンは(100msec後)保温モードへ押されたことを通知する
3. 保温モードは自身のモードと保温温度を対応づけられて変更する
// 高温から節約, 節約からミルク, ミルクから高温のいずれか
4. 保温モードはモード表示へ表示変更(モード)を指示する
5. 保温モードはブザーへ単発鳴動を指示する
// この時点で保温モードの変更にはなっている
6. 保温モードは温度制御の水温を確認する // 100°C未満
7. 保温モードはポットへ沸騰要求を通知する
8. ポットは水位の位置と満水を確認する
9. ポットは温度制御へ, 沸騰を指示する  // ポットは加熱中(沸騰行為)へ遷移
// 以後, 蓋閉から...の "ポットは温度制御へ, 沸騰を指示する" の流れへ乗る
// その後の過程の "ポットは温度制御へ保温(保温温度)を指示する" で保温モードの温度が適用された保温が始まる

## 解除ボタン押下から給湯モードが解除されるを経由して給湯ボタンで給湯されるまで

### 事前条件

給湯中(保温行為)でないこと
蓋が閉じていること
給湯口がロックされていること

### 事後条件

給湯中(保温行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは解除ボタンを押す
2. 解除ボタンは(100msec後)給湯口へ押されたことを通知する
3. 給湯口は自身のロックを解除する // 実際は反転処理
4. 給湯口はブザーを単発鳴動を指示する
5. 給湯口はロックランプを消灯する
// Userは解除ボタンを開放する
6. Userは給湯ボタンを押す
7. 給湯ボタンは給湯口へ押されたことを通知する
8. 給湯口はポットへ給湯要求を通知する
9. ポットは自身が保温中(保温行為)であるかを確認する // 温度エラーと電源含む
10. ポットは蓋へ閉であるかを確認する
11. ポットは水位へ空でないか, 満水でないかを確認する
12. ポットは給湯口へ給湯開始を指示する // ポットは給湯中(保温行為)へ遷移
13. 給湯口はポンプへ作動を指示する
14. 給湯口は解除ボタンへ有効性の無効を指示する
15. ポットは保温モードへ給湯開始を指示する
16. 保温モードは沸騰ボタンへ有効性の無効を指示する

## 解除ボタン押下から給湯モードがロックされるまで

### 事前条件

給湯中(保温行為)でないこと
蓋が閉じていること
給湯口のロックが解除されていること

### 事後条件

給湯口がロックになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは解除ボタンを押す
2. 解除ボタンは(100msec後)給湯口へ押されたことを通知する
3. 給湯口は自身のロックをロックにする // 実際には反転処理
4. 給湯口はブザーへ単発鳴動を指示する
5. 給湯口はロックランプを点灯させる
// Userは解除ボタンを開放する

## 貯水部の水がなくなり保温が停止されるまで

### 事前条件

保温中(保温行為)であること

### 事後条件

アイドルになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

// 保温の制御でいつしか水がなくなる
2. 水位は全ての水位センサがOFFとなったことを検知する // 状況として最下段のセンサ
3. 水位は最下段のインジケータセルを消灯する
// 蓋のタイミングではないので, 空の判断が走らない
4. 水位はポットへ全センサOFFを通知する
// ポットは自身へ温度制御停止を通知する
5. ポットは温度制御へ制御なしを指示する // ポットはアイドルへ遷移
6. 温度制御は温度表示へ表示なしを指示する
// 以後, 温度制御の温度出力の指示は実行されなくなる
7. ポットは温度エラー監視へ監視なしを指示する
8. ポットは保温モードへ保温行為の終了を通知する
9. 保温モードは沸騰ボタンへ有効性の無効を指示する
10. ポットは給湯口へ保温行為の終了を通知する
11. 給湯口は給湯ボタンへ有効性の無効を指示する
12. ポットはランプの点灯を変える {沸騰ランプ消灯, 保温ランプ消灯}

## 沸騰開始から高温エラー発生まで

### 事前条件

加熱中(沸騰行為)であること
サーミスタが111°Cを示す状況であること

### 事後条件

エラーになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. 温度制御はサーミスタの検出値を水温として読み出す
2. 温度エラー監視は温度制御の水温と目標温度を読み出す
3. 温度エラー監視は高温エラー検出を実施する
// 111°Cなので引っかかる
4. 温度エラー監視はポットへ温度エラー検出を通知する
5. ポットは温度制御へ制御なしを指示する // ポットはエラーへ遷移
6. 温度制御は温度表示へ表示なしを指示する
// 以後, 温度制御の温度出力の指示は実行されなくなる
7. ポットは温度制御へヒータ用電源OFFを指示する
8. ポットは温度エラー監視へ監視なしを指示する
9. ポットはブザーへ30秒鳴動を指示する
10. ポットはランプの点灯を変える {沸騰ランプ消灯, 保温ランプ消灯}
