# コミュニケーション図 事前/事後条件・シナリオ

## 蓋閉から沸騰開始を経由して保温まで

### 事前条件

水が適量であること
蓋が開いていること

### 事後条件

保温中(保温行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは蓋を閉める
2. 蓋は(3sec後)ポットへ蓋閉を通知する
3. ポットは水位へ水位更新を指示する
4. 水位は水位センサに対応したインジケータセルへ点灯または消灯を指示する
// 水位センサonでは点灯, offでは消灯
5. ポットは給湯口へ蓋閉を通知する
6. 給湯口は解除ボタンへ有効化を指示する
7. ポットは保温モードへ蓋閉を通知する
8. 保温モードは保温設定ボタンへ有効化を指示する
// ポットは自身へ沸騰要求を通知する
9. ポットは水位へ位置が0でないかと満水でないかを確認する
10. ポットは温度制御へ, 沸騰を指示する  // ポットは加熱中(沸騰行為)へ遷移
11. 温度制御はサーミスタの検出値を読み出して水温とする
// この値取得の工程明記は, もし温度制御がヒータの制御に関係なしに常に定期的に実行しているなら, 不要
12. 温度制御は温度表示へ水温での表示を指示する
// 以後, この水温での表示の指示は温度制御のサーミスタ読み取りの周期で定期実行
13. ポットは温度エラー監視へ, 加熱監視を指示する
14. ポットはランプの点灯を変える {沸騰ランプ点灯, 保温ランプ消灯}
// 待ち. 温度制御はサーミスタとヒータと温度表示を, 温度エラー監視は温度制御の水温を, 定期で更新
15. 温度制御は沸点到達をポットへ通知する
16. ポットは温度制御へ, カルキ抜きを指示する // ポットはカルキ抜き中(沸騰行為)へ遷移
17. ポットは温度エラー監視へ, カルキ抜き監視を指示する
// 待ち. 上の待ちと大体同じ.
18. 温度制御は(3分経過後)沸騰処理完了をポットへ通知する
19. ポットは保温モードの保温温度を読み出す // ポットは保温中(保温行為)へ遷移
20. ポットは温度制御へ上記の保温温度での保温を指示する
21. ポットは温度エラー監視へ保温監視を指示する
22. ポットは保温モードへ保温行為の開始を通知する
23. 保温モードは沸騰ボタンへ有効化を指示する
24. ポットは給湯口へ保温行為の開始を通知する
25. 給湯口は給湯ボタンへ有効化を指示する
26. ポットはブザーへ3回鳴動を指示する
27. ポットはランプの点灯を変える {沸騰ランプ消灯, 保温ランプ点灯}

## 沸騰ボタン押下から沸騰開始まで

### 事前条件

保温中(保温行為)であること

### 事後条件

加熱中(沸騰行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは沸騰ボタンを押す
2. 沸騰ボタンは(100msec後)押されたことを保温モードに通知する
3. 保温モードはブザーへ単発鳴動を指示する
4. 保温モードはポットへ沸騰要求を通知する
5. ポットは水位へ位置が0でないかと満水でないかを確認する
6. ポットは保温モードへ保温行為の終了を通知する // ポットは加熱中(沸騰行為)へ遷移
7. 保温モードは沸騰ボタンへ無効化を指示する
8. ポットは給湯口へ保温行為の終了を通知する
9. 給湯口は給湯ボタンへ無効化を指示する
10. ポットは温度制御へ, 沸騰を指示する
// 以後, 蓋閉から...の "ポットは温度制御へ, 沸騰を指示する" 以降と同一

## 保温モードボタン押下から保温モードが変更されるまで

### 事前条件

蓋が閉じていること

### 事後条件

保温モードが変更されていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは保温設定ボタンを押す
2. 保温設定ボタンは(100msec後)保温モードへ押されたことを通知する
3. 保温モードはブザーへ単発鳴動を指示する
4. 保温モードは自身のモードを次のモードへ変更する
// 高温から節約, 節約からミルク, ミルクから高温のいずれか
5. 保温モードは保温温度を上記で変更したモードに対応づけられた温度へ変更する
6. 保温モードはモード表示へ上記で変更したモードでの表示変更を指示する
// この時点で保温モードの変更にはなっている
// 保温モードの温度が適用された保温が始まるのは沸騰処理完了後の保温行為となるとき
// 保温モードは温度制御の水温を読み出し, 100°C未満であればポットへ沸騰要求を通知する
// その以後は沸騰ボタン押下から...の "保温モードはポットへ沸騰要求を通知する" 以降と同一

## 解除ボタン押下から給湯モードが解除されるを経由して給湯ボタンで給湯されるまで

### 事前条件

保温中(保温行為)であること
蓋が閉じていること
給湯口がロックされていること

### 事後条件

給湯中(保温行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは解除ボタンを押す
2. 解除ボタンは(100msec後)給湯口へ押されたことを通知する
3. 給湯口は自身のロックを解除する // 実際は反転処理
4. 給湯口はブザーへ単発鳴動を指示する
5. 給湯口はロックランプへ消灯を指示する
// Userは解除ボタンを開放する
6. Userは給湯ボタンを押す
7. 給湯ボタンは給湯口へ押されたことを通知する
8. 給湯口はポットへ給湯要求を通知する
9. ポットは自身が保温中(保温行為)であるかを確認する // 温度エラーと電源含む
10. ポットは蓋へ閉であるかを確認する
11. ポットは水位へ位置が0でないかと満水でないかを確認する
12. ポットは給湯口へ給湯開始を指示する // ポットは給湯中(保温行為)へ遷移
13. 給湯口はポンプへ作動を指示する
14. 給湯口は解除ボタンへ無効化を指示する
15. ポットは保温モードへ給湯開始を通知する
16. 保温モードは沸騰ボタンへ無効化を指示する

## 解除ボタン押下から給湯モードがロックされるまで

### 事前条件

給湯中(保温行為)でないこと
蓋が閉じていること
給湯口のロックが解除されていること

### 事後条件

給湯口がロックになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは解除ボタンを押す
2. 解除ボタンは(100msec後)給湯口へ押されたことを通知する
3. 給湯口は自身のロックをロック状態にする // 実際には反転処理
4. 給湯口はブザーへ単発鳴動を指示する
5. 給湯口はロックランプへ点灯を指示する
// Userは解除ボタンを開放する

## 貯水部の水がなくなり保温が停止されるまで

### 事前条件

保温中(保温行為)であること

### 事後条件

アイドルになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

// 保温の制御でいつしか水がなくなる
1. 水位は全ての水位センサがoffとなったことを検知する // 状況として最下段のセンサ
2. 水位は最下段のインジケータセルへ消灯を指示する
// 蓋のタイミングではないので, 空の判断が走らない
3. 水位はポットへ全センサoffを通知する
// ポットは自身へ温度制御停止を通知する
4. ポットは温度制御へ制御なしを指示する // ポットはアイドルへ遷移
5. 温度制御は温度表示へ表示なしを指示する
// 以後, 温度制御の水温での表示の指示は実行されなくなる
6. ポットは温度エラー監視へ監視なしを指示する
7. ポットは保温モードへ保温行為の終了を通知する
8. 保温モードは沸騰ボタンへ無効化を指示する
9. ポットは給湯口へ保温行為の終了を通知する
10. 給湯口は給湯ボタンへ無効化を指示する
11. ポットはランプの点灯を変える {沸騰ランプ消灯, 保温ランプ消灯}

## 沸騰開始から高温エラー発生まで

### 事前条件

加熱中(沸騰行為)であること
サーミスタが111°Cを示す状況であること

### 事後条件

エラーになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. 温度制御はサーミスタの検出値を読み出して水温とする
2. 温度エラー監視は温度制御の水温を読み出す
// 温度エラー監視は温度制御の目標温度を読み出す
3. 温度エラー監視は高温エラー検出を実施する
// 111°Cなので引っかかる
4. 温度エラー監視はポットへ温度エラー検出を通知する
5. ポットは温度制御へ制御なしを指示する // ポットはエラーへ遷移
6. 温度制御は温度表示へ表示なしを指示する
// 以後, 温度制御の水温での表示の指示は実行されなくなる
7. ポットは温度制御へヒータ用電源offを指示する
8. ポットは温度エラー監視へ監視なしを指示する
9. ポットはブザーへ30秒鳴動を指示する
10. ポットはランプの点灯を変える {沸騰ランプ消灯, 保温ランプ消灯}

加熱中(沸騰行為)であること
サーミスタが徐々に低い温度を示す状況であること
今回水温が目標温度より8°C(以上)低い状況であること

エラーになっていること

// "//"はそこから行末までコメントとしてほしい.

4. 温度エラー監視は温度上がらずエラー検出を実施する
// 事前条件より前回水温より低いものとして引っかかる
5. 温度エラー監視はポットへ温度エラー検出を通知する
6. ポットは温度制御へ制御なしを指示する // ポットはエラーへ遷移
7. 温度制御は温度表示へ表示なしを指示する
// 以後, 温度制御の水温での表示の指示は実行されなくなる
8. ポットは温度制御へヒータ用電源offを指示する
9. ポットは温度エラー監視へ監視なしを指示する
10. ポットはブザーへ30秒鳴動を指示する
11. ポットはランプの点灯を変える {沸騰ランプ消灯, 保温ランプ消灯}
