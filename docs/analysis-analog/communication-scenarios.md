# コミュニケーション図 事前/事後条件・シナリオ

### 事前条件

水が適量であること
蓋が開いていること

### 事後条件

保温中(保温行為)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは蓋を閉める
2. 蓋は蓋センサの検出値を読み出す // onである
3. 蓋は(3sec後)ポットへ蓋閉を通知する [pot-220-11]
4. ポットは操作部へ蓋閉を通知する
5. 操作部は解除ボタンへ有効化を指示する [pot-250-21]
6. 操作部は保温設定ボタンへ有効化を指示する [pot-240-21]
// ポットは自身へ沸騰要求を通知する

14. 温度制御はヒータへ操作量MでPWM変更を指示する [pot-400-11]

18. 温度制御は沸点到達をポットへ通知する
// ポットは自身の現在状態をカルキ抜き中(沸騰行為)に切り替える
19. ポットはカルキ抜き中(沸騰行為)へ遷移を指示する [pot-311-11]
20. カルキ抜き中(沸騰行為)は温度制御へ, カルキ抜きを指示する
21. カルキ抜き中(沸騰行為)は温度エラー監視へ, カルキ抜き監視を指示する
// 待ち. 上の待ちと大体同じ.
22. 温度制御は(3分経過後)沸騰処理完了をポットへ通知する [pot-312-11]
// ポットは自身の現在状態を保温中(保温行為)に切り替える
23. ポットは保温中(保温行為)へ遷移を指示する [pot-240-31]
24. 保温中(保温行為)は保温モードの保温温度を読み出す

28. 操作部は沸騰ボタンへ有効化を指示する [pot-230-11]
29. 操作部は給湯口のロックを読み出す // 解除だったとする

33. 保温中(保温行為)は表示部へランプ点灯変更を指示する {沸騰ランプ消灯, 保温ランプ点灯} [pot-320-11]

## 沸騰開始から温度上がらずエラー発生まで

今回水温が目標温度より8°C(以上)低い状況であること

エラーになっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

// このエラーの検出周期は1分である
1. 温度制御はサーミスタの検出値を読み出して水温とする
2. 温度エラー監視は温度制御の水温を読み出す
3. 温度エラー監視は温度制御の目標温度を読み出す
4. 温度エラー監視は温度上がらずエラー検出を実施する [pot-500-31]
// 事前条件より前回水温より低いものとして引っかかる
5. 温度エラー監視はポットへ温度エラー検出を通知する
// ポットは自身の現在状態をエラーに切り替える
