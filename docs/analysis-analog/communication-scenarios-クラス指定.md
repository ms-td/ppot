# コミュニケーション図 事前/事後条件・シナリオ

## 蓋閉から沸騰開始を経由して保温まで

### 事前条件

水が適量であること
蓋が開いていること

### 事後条件

保温行為(サブ状態=保温中)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは蓋を閉める
2. 蓋は蓋センサの検出値を読み出す // onである
3. 蓋は(3sec後)ポットへ蓋閉を通知する [pot-220-11]
4. ポットはアイドルへ蓋閉を通知する
5. アイドルは水位へ水量が適量かを確認する [pot-220-21] // 遷移条件のガード
6. アイドルはポットへ沸騰要求を通知する
// ポットは自身の現在状態を沸騰行為に切り替える
7. ポットは沸騰行為へ遷移を指示する [pot-310-21, pot-400-21]
8. 沸騰行為はサブ状態を加熱中にし, 温度制御器へ制御開始を指示する {目標温度=100°C, 方式=目標温度ON/OFF方式} [pot-310-21]
9. 温度制御器はサーミスタの検出値を読み出し, 現在水温とする
// この値取得の工程明記は, もし温度制御器がヒータの制御に関係なしに常に定期的に実行しているなら, 不要
10. 温度制御器は表示部へ温度表示を指示する [pot-310-12]
11. 表示部は温度表示へ水温での表示を指示する
// 以後, この水温での表示の指示は温度制御器のサーミスタ読み取りの周期で定期実行
12. 温度制御器はヒータへ作動を指示する
13. 温度制御器はヒータへ操作量MでPWM変更を指示する [pot-400-11]
14. 沸騰行為は温度エラー監視へ監視開始を指示する {高温エラー, 温度上がらずエラー}
15. 沸騰行為は表示部へランプ点灯変更を指示する {沸騰ランプ点灯, 保温ランプ消灯} [pot-310-11]
16. 表示部はランプの点灯を変える
// 待ち. 温度制御器はサーミスタとヒータと温度表示を, 温度エラー監視は温度制御器の水温を, 定期で更新
// また, 定期で沸騰行為は温度制御器の水温を読む.
17. 沸騰行為は温度制御器の水温を読む. // 100°Cである. 沸点到達 [pot-311-11]
// 沸騰行為はサブ状態をカルキ抜き中にする.
// 沸騰行為は再度(リセットのため), 温度エラー監視へ監視開始を指示する {高温エラー, 温度上がらずエラー}
// 待ち. 上の待ちと大体同じ.
18. 沸騰行為は(3分経過後)沸騰処理完了をポットへ通知する [pot-312-11]
// ポットは沸騰行為へ退場を指示する.
// 沸騰行為は温度制御器へ制御停止, 温度エラー監視へ監視停止を指示する.
// ポットは自身の現在状態を保温行為に切り替える
19. ポットは保温行為へ遷移を指示する [pot-240-31]
20. 保温行為は保温モードへ保温温度読み出す // サブ状態=保温中
21. 保温行為は温度制御器へ制御開始を指示する {目標温度=保温温度, 方式=PID制御方式} [pot-320-21, pot-400-31]
22. 保温行為は温度エラー監視へ監視開始を指示する {高温エラー, 温度上がらずエラー, 温度下がらずエラー}
23. 保温行為は表示部へ3回鳴動を指示する
24. 表示部はブザーへ3回鳴動を指示する
25. 保温行為は表示部へランプ点灯変更を指示する {沸騰ランプ消灯, 保温ランプ点灯} [pot-320-11]
26. 表示部はランプの点灯を変える

## 沸騰ボタン押下から沸騰開始まで

### 事前条件

保温行為(サブ状態=保温中)であること

### 事後条件

沸騰行為(サブ状態=加熱中)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは沸騰ボタンを押す
2. 沸騰ボタンは(100msec後)押されたことを操作部に通知する [pot-230-11]
3. 操作部はポットへ沸騰ボタン押下を通知する
4. ポットは保温行為へ沸騰ボタン押下を通知する
// 保温行為は自身が給湯中でないかを確認する // 遷移条件のガード
// 水位の水量が適量か, 蓋が閉じているかは保温行為では自明
5. 保温行為は表示部へ単発鳴動を指示する
6. 表示部はブザーへ単発鳴動を指示する
7. 保温行為はポットへ沸騰要求を通知する
8. ポットは保温行為(サブ状態=保温中)へ退場を指示する
// 保温行為は温度制御器へ制御停止, 温度エラー監視へ監視停止を指示する.
// ポットは自身の現在状態を沸騰行為に切り替える
9. ポットは沸騰行為へ遷移を指示する [pot-310-21, pot-400-21]
10. 沸騰行為はサブ状態を加熱中にし, 温度制御器へ制御開始を指示する {目標温度=100°C, 方式=目標温度ON/OFF方式} [pot-310-21, pot-400-21]
// 以後, 蓋閉から...の "沸騰行為はサブ状態を加熱中にし, 温度制御器へ制御開始を指示する {目標温度=100°C, 方式=目標温度ON/OFF方式}" 以降と同一

## 保温モードボタン押下から保温モードが変更されるまで

### 事前条件

蓋が閉じていること

### 事後条件

保温モードが変更されていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは保温設定ボタンを押す
2. 保温設定ボタンは(100msec後)操作部へ押されたことを通知する [pot-240-21]
3. 操作部はポットへ保温設定押下を通知する
4. ポットは保温行為へ保温設定押下を通知する
// 保温行為では蓋の閉じているかは自明
5. 保温行為は表示部へ単発鳴動を指示する
6. 表示部はブザーへ単発鳴動を指示する
7. 保温行為は保温モードへ保温設定変更を指示する
8. 保温モードは自身のモードを次のモードへ変更する
// 高温から節約, 節約からミルク, ミルクから高温のいずれか
9. 保温モードは保温温度を上記で変更したモードに対応づけられた温度へ変更する [pot-240-31]
10. 保温モードは表示部へ上記で変更したモードでモード表示変更を指示する [pot-240-41]
11. 表示部はモード表示へ表示を指示する
// この時点で保温モードの変更にはなっている
// 保温モードの温度が適用された保温が始まるのは沸騰処理完了後の保温行為となるとき
// 保温行為は温度制御器の水温を読み出し, 100°C未満であれば, 給湯中ならそれを止めつつ, その以後は沸騰ボタン押下から...の "保温行為はポットへ沸騰要求を通知する" 以降と同一

## 解除ボタン押下から給湯モードが解除されるを経由して給湯ボタンで給湯されるまで

### 事前条件

保温行為(サブ状態=保温中)であること
蓋が閉じていること
給湯口がロックされていること

### 事後条件

保温行為(サブ状態=給湯中)になっていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは解除ボタンを押す
2. 解除ボタンは(100msec後)操作部へ押されたことを通知する [pot-250-21]
3. 操作部はポットへ解除押下を通知する
4. ポットは保温行為へ解除押下を通知する
// 保温行為は自身が給湯中でないか確認する
// 保温行為では蓋の閉じているかは自明
5. 保温行為は表示部へ単発鳴動を指示する
6. 表示部はブザーへ単発鳴動を指示する
7. 保温行為は給湯口へロック変更を指示する
8. 給湯口は自身のロックを解除する // 実際は反転処理
9. 給湯口は表示部へロック解除で給湯ロック切り替えを通知する
10. 表示部はロックランプを消灯する [pot-250-21]
// Userは解除ボタンを開放する
11. Userは給湯ボタンを押す
12. 給湯ボタンは操作部へ押されたことを通知する
13. 操作部はポットへ給湯要求を通知する
14. ポットは保温行為へ給湯要求を通知する
15. 保温行為は給湯口へロックが解除かを確認する
// 保温行為では蓋の閉じているか, 水位の水量が適量かは自明
16. 保温行為はサブ状態を給湯中にし, 給湯口へ給湯開始を指示する [pot-260-11]
17. 給湯口はポンプへ作動を指示する [pot-110-20]

## 沸騰開始から温度上がらずエラー発生まで

### 事前条件

沸騰行為(サブ状態=加熱中)であること
サーミスタが徐々に低い温度を示す状況であること
今回水温が目標温度より8°C(以上)低い状況であること

### 事後条件

エラーであること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

// このエラーの検出周期は1分である
1. 温度制御器はサーミスタの検出値を読み出し, 現在水温とする
2. 温度エラー監視は温度制御器から現在水温を読み出す
3. 温度エラー監視は温度制御器から目標温度を読み出す
4. 温度エラー監視は温度上がらずエラー判定へ判定を指示する [pot-500-31]
// 事前条件より前回水温より低いものとして引っかかる
5. 温度エラー監視はポットへ温度エラー検知を通知する
6. ポットは沸騰行為へ退場を指示する
7. 沸騰行為は温度制御器へ制御停止を指示する
8. 温度制御器はヒータへ停止を指示する [pot-400-11]
