# コミュニケーション図 事前/事後条件・シナリオ

## 蓋閉から沸騰開始を経由して保温まで

### 事前条件

水が適量であること
蓋が開いていること
ポット状態がアイドルであること

### 事後条件

ポット状態が保温であること
保温行為(サブ状態=保温中)が開始されていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは蓋を閉める
2. 蓋は蓋センサの検出値を読み出す // onである
3. 蓋はポットへ蓋の開閉変化(閉じた)を通知する [pot-220-11]
4. ポットは水位へ水量が適量かを確認する [pot-220-21] // trueである
5. ポットはポット状態へ沸騰要求を通知する
6. ポット状態は状態を沸騰へ変更し, 沸騰行為へ開始を指示する [pot-310-21, pot-400-21]
7. 沸騰行為はサブ状態を加熱中にする
8. 沸騰行為はサーミスタの検出値を読み出し, 現在水温とする
9. 沸騰行為は表示部へ温度表示を指示する [pot-310-12]
10. 表示部は温度表示へ水温での表示を指示する
11. 沸騰行為はヒータへ作動を指示する
12. 沸騰行為はヒータへ操作量MでPWM変更を指示する [pot-400-11]
13. 沸騰行為は温度エラー監視へ監視開始を指示する {高温, 温度上がらず}
14. 温度エラー監視は高温エラー判定と温度上がらずエラー判定を判定中にする
15. 沸騰行為は表示部へランプ点灯変更を指示する {沸騰ランプ点灯, 保温ランプ消灯} [pot-310-11]
16. 表示部はランプの点灯を変える
// 待ち. 沸騰行為はサーミスタとヒータと温度表示を, 温度エラー監視は選択された判定を, 定期で更新する.
17. 沸騰行為はサーミスタの検出値を読み出す // 100°Cである. 沸点到達 [pot-311-11]
// 沸騰行為はサブ状態をカルキ抜き中にする.
// 沸騰行為は温度エラー監視へ監視開始を再指示する {高温, 温度上がらず}. 選択された判定は数え直す.
18. 沸騰行為は(3分経過後)ポット状態へ沸騰処理完了を通知する [pot-312-11]
19. ポット状態は沸騰行為へ停止を指示する
20. 沸騰行為はヒータへ停止を指示する
21. 沸騰行為は温度エラー監視へ監視停止を指示する
22. ポット状態は状態を保温へ変更し, 保温行為へ開始を指示する [pot-240-31]
23. 保温行為は保温モードの保温温度を読み出す
24. 保温行為はサーミスタの検出値を読み出し, 現在水温とする
25. 保温行為はヒータへ作動を指示する
26. 保温行為はヒータへ操作量MでPWM変更を指示する [pot-400-31]
27. 保温行為は温度エラー監視へ監視開始を指示する {高温, 温度上がらず, 温度下がらず}
28. 温度エラー監視は3つの温度エラー判定を判定中にする
29. 保温行為は表示部へ3回鳴動を指示する
30. 表示部はブザーへ3回鳴動を指示する
31. 保温行為は表示部へランプ点灯変更を指示する {沸騰ランプ消灯, 保温ランプ点灯} [pot-320-11]
32. 表示部はランプの点灯を変える

1. Userは保温設定ボタンを押す
2. 保温設定ボタンは(100msec後)操作部へ押されたことを通知する [pot-240-21]
3. 操作部はポットへボタン押下(保温設定)を通知する
4. ポットは蓋へ閉じてるかを確認する
5. 蓋は蓋センサの検出値を読み出す // onである
6. ポットは表示部へ単発鳴動を指示する [pot-240-21]
7. 表示部はブザーへ単発鳴動を指示する
8. ポットは保温モードへ保温設定変更を指示する
9. 保温モードは自身のモードを次のモードへ変更する
// 高温から節約, 節約からミルク, ミルクから高温のいずれか.
10. 保温モードは保温温度を上記で変更したモードに対応づけられた温度へ変更する [pot-240-31]

// 保温行為が現在水温を読み出し, 100°C未満であれば, 給湯中ならそれを止めつつ, ポット状態へ沸騰要求を通知する.
// 以後は沸騰ボタン押下から...の "ポットはポット状態へ沸騰要求を通知する" 以降と同一.

## 解除ボタン押下から給湯モードが解除されるを経由して給湯ボタンで給湯されるまで

### 事前条件

ポット状態が保温であること
保温行為(サブ状態=保温中)であること
蓋が閉じていること
給湯口がロックされていること

### 事後条件

給湯口のロックが解除され, 給湯ボタン押下中に給湯されること
給湯ボタン開放後は保温行為(サブ状態=保温中)に戻っていること

### シナリオ:基本

// "//"はそこから行末までコメントとしてほしい.

1. Userは解除ボタンを押す
2. 解除ボタンは(100msec後)操作部へ押されたことを通知する [pot-250-21]
3. 操作部はポットへボタン押下(解除)を通知する
4. ポットは蓋へ閉じてるかを確認する // trueである
5. ポットはポット状態へ給湯ロック変更要求を通知する
6. ポット状態は現在状態が保温なので, 保温行為へ給湯中でないかを確認する
7. ポット状態は表示部へ単発鳴動を指示する
8. 表示部はブザーへ単発鳴動を指示する
9. ポット状態は給湯口へロック変更を指示する
10. 給湯口は自身のロックを解除する // 実際は反転処理
11. 給湯口は表示部へロック解除で給湯ロック切り替えを通知する
12. 表示部はロックランプを消灯する [pot-250-21]
// Userは解除ボタンを開放する.
13. Userは給湯ボタンを押す
14. 給湯ボタンは操作部へ押されたことを通知する
15. 操作部はポットへボタン押下(給湯)を通知する
16. ポットはポット状態へ給湯要求を通知する
17. ポット状態は保温行為へ給湯要求を通知する
18. 保温行為は給湯口へロックが解除かを確認する
// 保温行為中である時点で, 水量適正, 蓋センサon, ヒータ用電源on, 温度エラー未検知は満たされているものとして扱う.
19. 保温行為はサブ状態を給湯中にし, 給湯口へ給湯開始を指示する [pot-260-11]
20. 給湯口はポンプへ作動を指示する [pot-110-20]
21. Userは給湯ボタンを開放する
22. 給湯ボタンは操作部へ開放されたことを通知する
23. 操作部はポットへボタン開放(給湯)を通知する
24. ポットはポット状態へ給湯要求解除を通知する
25. ポット状態は保温行為へ給湯要求解除を通知する
26. 保温行為はサブ状態を保温中に戻し, 給湯口へ給湯停止を指示する
27. 給湯口はポンプへ停止を指示する
