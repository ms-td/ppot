A. `pot-500-21` が自然冷却中に成立するか?

`pot-500-21` "保温の各モードになって3分以上水温が98°C を超えていた場合,
ヒータ用電源を off して 30秒間ブザーを鳴らす"である.
しかし, 貯水部は `pot-100-15`"断熱性の高いステンレス素材" なので, 100°C から 98°C までに3分以上かかることはないのだろうか?

=> ないこととする.

B. 給湯中に蓋を開けたときのポンプ

`pot-260-21` の途中停止条件は3つ:

- 水量が異常になる
- ヒータ用電源がoffになる
- 温度エラーを検知する

`pot-221-11` "蓋センサが1sec以上offとなったら、温度制御行為(沸騰行為または保温行為)を中止する" (アイドル状態になる) は ポンプには触れていないので,
蓋を開けても給湯が続くと解釈できてしまう.

=> 動作する

C. 給湯中の保温設定ボタン

`pot-240-21` より, 給湯中でも蓋が閉まっていれば, 保温設定ボタンは有効と読める.
そこで, 保温設定ボタンを押下すると `ハードウェア, その他の動作仕様` では, 水温が100°C未満であったとき1度沸騰させようとする.
このときも先のポンプ停止にはかからないので, 沸騰中に給湯が続くと解釈できる.

=> 止める

D. 各ボタンの押下時のブザー(1回鳴動)

`ハードウェア, その他の動作仕様` は "ボタンが押されたらブザーを1回鳴動" があるけど,
要求仕様のほうでは, 以下2つの言及がある.
- `pot-230-11` (沸騰ボタン)
- `pot-240-21` (保温設定ボタン) だけ.

給湯ボタンと解除ボタンも鳴らすべきか?

=> 鳴らす
